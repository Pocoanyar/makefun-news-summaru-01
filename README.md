A one-file program that writes a sourced summary of the world news of Wednesday 11 November 2026 — eleven stories across regions and beats, each with the outlet that reported it — to /output/entry.txt. The summary lives in summary.txt; main.py checks it against the competition's 1-2,000 character gate and copies it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
